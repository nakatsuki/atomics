Priorități rămase

PrioritateProblemăRecomandare
P0 condiționatCodul de răspuns HTTP nu poate fi garantat de fișierul HTML.La publicare, orice adresă inexistentă trebuie să afișeze această pagină și să răspundă cu 404 Not Found, nu 200 OK. Dacă răspunde 200, remedierea este critică pentru SEO.
P1Pagina încarcă pachetul general: aproximativ 1,43 MB JavaScript și 406 KB CSS.Pe termen mediu, creați un bundle minim pentru 404 sau extrageți doar headerul, animația necesară și footerul. Nu este recomandată eliminarea directă a bundle-ului actual: controlează animațiile și scrollul paginii.
P1Există 38 de imagini în document, în mare parte decorative.Convertiți PNG/JPEG mari în WebP/AVIF și folosiți variante responsive. Păstrați ilustrația 404, dar comprimați activele.
P2Titlurile acordeonului mobil din footer sunt elemente H3 controlate prin JavaScript.Într-o revizie a componentelor globale, folosiți butoane reale cu aria-expanded și control complet din tastatură.
P2Monitorizarea erorilor 404 nu mai pornește înaintea consimțământului.Dacă este necesară analiza URL-urilor greșite, trimiteți un eveniment 404 numai după consimțământul pentru analytics.

Checklist de publicare

  • Deschideți o adresă care nu există, de exemplu /pagina-test-inexistenta.
  • Confirmați în Network sau cu curl -I că răspunsul este 404.
  • Confirmați că serverul folosește 404.html drept document de eroare.
  • Retestați homepage-ul și formularul de contact după publicare.
